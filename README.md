# Remaining Birth Days

A simple birthday counter project that calculates how many days are left until the next birthday.

## live link:   

## Features

- Enter a birth day and month in a clean browser form.
- Shows the number of days left until the next birthday.
- Displays `Happy Birthday!` when the count is `0`.
- Supports leap-day birthdays like `29 February`.

## Files

- `index.html` - Main HTML page for the browser version.
- `style.css` - Styling for the form and result card.
- `script.js` - JavaScript logic for validation and countdown calculation.
- `project.py` - Original Python console version of the birthday counter.
